# Python for Data Analysis: Learning Through Building Data

A self-study course in Jupyter notebooks, following the ideas of Wes McKinney's *Python for Data Analysis, 3rd Edition* and practised on building electricity and weather data (structured like Building Data Genome 2).

Each session is **one self-contained notebook**: short explanations, runnable code, exercises with automatic `assert` checks, and challenges on building data. Everything is written in our own words (nothing is copied from the book).

---

## Getting started

The project uses [`uv`](https://github.com/astral-sh/uv) (Python 3.12+, NumPy 2.x, pandas 3.x, pyarrow, JupyterLab).

```bash
git clone https://github.com/daFoggo/python-for-data-analysis.git
cd python-for-data-analysis
uv sync
uv run jupyter lab
```

(Or open the folder in VS Code and pick the `.venv` environment as the Jupyter kernel.) Open notebooks from the project root; they also find `data/` if you open them from `notebooks/`.

## Data (`data/`)

This is a **small simulated dataset** generated by `scripts/prepare_sample_data.py` to mimic the structure of [BDG2](https://github.com/buds-lab/building-data-genome-project-2) (Miller et al., 2020, *Scientific Data* 7, 368). It is not real measurements. The real BDG2 has 1,636 buildings, 3,053 meters and two years (2016-2017).

- `building_metadata.csv`: 10 buildings across 4 sites: primary use, floor area, year built, time zone.
- `weather.parquet`: hourly weather per site.
- `building_telemetry.parquet`: hourly electrical power (kW) for the 10 buildings across 2023 (87,600 rows).

Regenerate it with `uv run python scripts/prepare_sample_data.py`.

## Editing and checking the notebooks

The notebooks are **generated from `scripts/content_XX.py`** (through `scripts/nbkit.py`). Edit the content there and rebuild, rather than editing the `.ipynb` files by hand:

```bash
uv run python scripts/build_notebooks.py      # rebuild notebooks/*.ipynb
uv run python scripts/validate_notebooks.py   # run the solved version + every assert
```

The learner notebooks contain blanks (`___`) and empty cells. The validator uses the solutions stored alongside in `content_XX.py` to confirm every exercise is solvable and every `assert` passes. Cells that use IPython syntax (`%timeit`, `?`) are skipped during validation.
